# Mis ejercicios de Java

Colección de siete ejercicios académicos realizados durante el aprendizaje inicial de Java.

## Temas practicados
- Entrada de datos con `Scanner`.
- Variables y operaciones aritméticas.
- Condicionales `if`, `else if` y `else`.
- Ciclos `for` y `while`.
- Ciclo `do-while`.
- Selección múltiple con `switch`.
- Contadores, acumuladores y variables booleanas.

## Compilar y ejecutar
Abre una terminal en esta carpeta y compila el archivo que quieras ejecutar:

```bash
javac Ejercicio.java
java Ejercicio
```

Repite el procedimiento cambiando el nombre de la clase/archivo.

> Nota: Son ejercicios de práctica académica de nivel inicial. Se corrigieron errores de ejecución y comparaciones evidentes, conservando la idea original de cada ejercicio.
